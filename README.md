# AI 자유 채팅

브라우저에서 Gemini와 대화하는 정적 웹페이지입니다.

## 사용 방법

1. Google AI Studio에서 Gemini API 키를 발급합니다.
2. 사이트 오른쪽 위의 **설정**에 키를 입력합니다.
3. 메시지를 입력해 대화를 시작합니다.

API 키는 사이트 코드에 포함되지 않으며, 입력한 브라우저의 로컬 저장소에만 보관됩니다. 대화 요청은 브라우저에서 Google Gemini API로 직접 전송됩니다.
